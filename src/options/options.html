Safety rules

Some responses are deliberately marked as uncacheable. Overriding those can expose private data or break sign-in flows, so they are skipped by default.

Resource types

Only subresources are modified. The page itself, frames, redirects and error responses are never changed.

Excluded sites and URLs

One pattern per line. * matches any text, and lines starting with # are comments.

Pattern examples
  • example.com — that exact host, any path, http or https.
  • *.example.com — any subdomain, but not example.com itself.
  • example.com/api/* — only paths under /api/.
  • https://example.com/* — only over HTTPS.

Advanced

Settings apply immediately to new responses. Files that are already cached keep their old lifetime until they expire or the page is reloaded.
